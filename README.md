## 📥 安装与导入（v1.1.7）

**第一步 · 装 App**：下载上方 APK 安装即可。

**第二步 · 导入正式角色稿（可选，想玩 5 正式角色才需要）**：

1. 到 [DLC 仓库](https://github.com/indhg/AI-for-Coyote-DLC/releases) 下载 **DLC-zh v0.4.1**（中文五角色）和/或 **DLC-en v0.4.0**（英文五角色）；不要用旧 DLC1/DLC2（已废弃，不兼容）；
2. 打开 App → 设置 → 角色入口卡 → **「导入 DLC（打开文件管理）」**，勾选下载的 zip（可多选，也可只选单个 md）；
3. 导入成功 → 对应入口从「未导入」**点亮**，点角色名选中即可开玩，无需重启 App；
4. 也可以在任何文件管理器/浏览器里把 zip / md「分享」给本 App 直接导入。

> 正式角色稿 = 露骨 R18 内容，仅在 DLC 官方仓库提供；体验版始终免费可用。

## ❓ FAQ

- **正式角色是灰的、点不了？** = 该角色内容包未导入。去 DLC 仓库下对应语言包，按上面「导入 DLC」导入即点亮；
- **观察行是灰的？** = 未授权相机/麦克风。不给授权也能玩，但没有观察反馈；
- **界面切了 English 但角色还是灰的？** = 该语言的角色稿没装（中文角色灰 = 装 DLC-zh；英文灰 = 装 DLC-en）；
- **导入 zip 提示失败？** = 确认是现行包（`content/roles/<角色>-角色提示词.md`，无 `-调教` 后缀），旧 legacy 包不兼容；
- **需要电脑/中继吗？** 不需要，手机 BLE 直连郊狼（v3.0）。

## 📥 Install & import（v1.1.7）

**1 · Install the app** from the link above.

**2 · Import official scripts（optional — only needed for the 5 adult roles）**：

1. Grab **DLC-zh v0.4.1**（Chinese）and/or **DLC-en v0.4.0**（English）from the [DLC repo](https://github.com/indhg/AI-for-Coyote-DLC/releases); do not use legacy DLC1/DLC2 packs（unsupported）;
2. Open the app → Settings → role card → **“Import DLC (open file manager)”** and pick the zip（multi-select allowed; single .md works too）;
3. On success the entry lights up from “Not installed” — tap the role name to select it; no restart needed;
4. You can also “Share” the zip/.md to this app from any file manager or browser.

> Official role scripts are explicit R18 content, provided only through the official DLC repo; the Trial is always free.

## ❓ FAQ

- **Official roles greyed out?** Their content pack isn’t imported — get the matching language pack and import it via “Import DLC”.
- **Observer line greyed?** Camera/mic permission missing. You can still play, but there is no observation feedback.
- **Switched UI to English but roles still grey?** The English scripts aren’t installed — import DLC-en.
- **Zip import failed?** Make sure it’s a current pack（`content/roles/<role>-角色提示词.md`, no `-调教` suffix）; legacy packs are rejected.
- **Do I need a PC or relay?** No — BLE connects straight to the Coyote（v3.0）.
